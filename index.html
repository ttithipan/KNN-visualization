How the mathematics works

Euclidean distance uses the Pythagorean theorem. Manhattan distance adds horizontal and vertical travel. Each selected neighbor contributes 1 vote, or 1/d for distance weighting. If a neighbor is exactly at the query, only exact matches vote. Ties go to the closest selected neighbor, then the lowest point ID. Both features use the same 0–10 scale.

Precision, recall & confusion matrix

TP / TN are correct positive / negative predictions. FP is a false alarm; FN is a missed positive. These counts use every point as a held-out example, not just the query.

Read the formulas

Precision = TP / (TP + FP): how often a positive prediction is correct.
Recall = TPR = TP / (TP + FN): how many actual positives are found.
F1 = 2TP / (2TP + FP + FN): balances precision and recall.
Accuracy = (TP + TN) / all points.
FPR = FP / (FP + TN): how many actual negatives trigger false alarms.
“—” means the denominator is zero, so that metric is undefined. Accuracy can hide poor minority-class recall; inspect both classes by changing the positive class.

What does this error mean?

We hide each point’s label, predict it from the other points, and count mistakes: error = incorrect predictions / total points. This is leave-one-out validation: each prediction uses at most N − 1 neighbors because the point itself is excluded. Lower is better, but the curve may rise or fall. KNN does not train or converge; Play runs until its prediction is complete.
